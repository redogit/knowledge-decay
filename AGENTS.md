# Repository-scoped instructions

Read README.md, CHARTER.md, research/PROOF_QUALIFICATIONS.txt, and NEXT_STEP.md before proposing changes.

- Preserve the human learning purpose; do not redefine Knowledge Decay as only its technical machinery.
- Preserve source text, authorship distinctions, chronology, uncertainty, counterexamples, failures, and recovery paths.
- Keep source-declared claim status separate from current review and verification. Imported proof labels are not new admissions.
- Keep object, occurrence, revision, representation, interpretation, group membership, and authority separate.
- Do not silently equate CHAINED and CHANGE identifiers or invent the missing Stairs of State source.
- Do not equate pairwise compatibility with a whole-group obligation, or unknown membership with exclusion.
- Freeze each proposed action's inputs, scope, budget, conditional successors, stop condition, and recovery route before executing it. Record actual outcomes, not reconstructed or imagined tool events.
- Keep original source snapshots immutable. New evidence is a new version with provenance, not a silent replacement.
- Source availability is explicit in provenance/SOURCE_IMPORT.json. An omitted public source is not nonexistent, and a hash is not a substitute for accessible bytes.
- No unrelated private data, raw private-history dumps, secrets, or font binaries belong in this public repository.
- Do not change other repositories, publish new private material, or run future experiments merely because this repository references them.
- Verify changed files and report exactly which tests ran. Artifact integrity, software behavior, mathematics, and human benefit are different claims.
